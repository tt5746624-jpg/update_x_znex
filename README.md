## X Znex v1.2.0

A major Game Booster and Material 3 UI update.

### New Features

- Added selected game icon and package information
- Added direct game launch button
- Added Performance, Balanced, and Battery Saver profiles
- Added FPS target control
- Added touch response boost
- Added network focus mode
- Added background cleanup option
- Added smart thermal guard
- Added battery protection target
- Added distraction control
- Added FPS and CPU overlay support
- Added persistent boost activity log
- Added boost session counter
- Added Device Snapshot and diagnostics activity
- Added RAM and battery information
- Added Material 3 update dialog
- Added GitHub `update.json` update system
- Added APK download link support

### Improvements

- Improved dark Material 3 color contrast
- Added X Znex app icon to the main dashboard
- Added X Znex icon to the update dialog
- Improved game selection card layout
- Improved button spacing and text truncation
- Moved advanced command access into a dedicated tool flow

### Requirements

- Android 7.0 or newer
- Shizuku is required for advanced system-level booster actions
- Some options depend on device and Android version support
